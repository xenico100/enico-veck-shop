# `/world` 몽상인 — 잠들지 않는 마을

`/world`는 몽상녀와 벡독이 함께 걷는 짧은 밤 산책 게임입니다. 기본은 3인칭이며 1인칭으로도 바꿀 수 있습니다. 승인된 마을 GLB와 기존 공간(우체국·잡화점·극장·주민 센터·카페·제작 연구소·dot 작업실) 연결 위에 PS1 시대의 질감과 밤의 이야기를 얹었습니다.

홈페이지의 기존 픽셀 마을에서는 중앙 분수 오른쪽 **WORLD 포탈**로 들어갑니다. 포탈을 클릭·터치하면 캐릭터가 입구까지 걸어가고, 직접 걸어서 들어가도 전체 화면 로딩을 거쳐 `/world`로 이동합니다. 이동이 지연되면 10초 후 **마을에 머무르기**로 취소할 수 있습니다. 기존 홈페이지와 공간 링크는 그대로 유지합니다.

## 이야기와 진행

자정이 지난 몽상로에서 눈을 뜬 플레이어는 마을이 잃어버린 "첫 문장"을 되찾아야 합니다.

| 장 | 목표 | 이벤트 |
| --- | --- | --- |
| 프롤로그 · 눈을 뜨다 | 서쪽 가로등 아래 손전등 줍기 | 시작 독백, 메모리 카드 자동 저장 |
| 1장 · 꺼지지 않는 가로등 | 꿈 조각 3개 | 3번째 조각 후 **정전**(24초), 그림자 첫 등장 |
| 2장 · 반송된 이름들 | NPC 3명에게서 단서 3개 | 비가 내리기 시작, 반송계 그림자·잡화점 고양이·영사기사 대화, 마지막 필름을 주우면 **기차 진동·창문 깜빡임** |
| 3장 · 첫 문장 | 울리는 공중전화 받기 → 꿈 조각 8개 | 8번째 조각에서 철길 너머 **첫 문장의 문** 개방 |
| 에필로그 · 새벽 | 자유 산책 | 화이트아웃 엔딩, 기록 카드, 새벽 하늘 모드 |

부가 요소: 읽을 수 있는 쪽지 5개, 건전지 3개, 한 번만 작동하는 자판기, 빨간 우체통, 꿈 일지(J), 지도(M)에 가로등·NPC·단서 위치 표시(3장부터 남은 조각 위치가 희미하게 보임).

## 밤의 규칙

- **숨**: 그림자가 가까우면 줄고, 가로등 빛 안에서 회복합니다. 0이 되면 "깨어날 뻔"하며 마지막 가로등으로 돌아갑니다. 진행은 잃지 않습니다.
- **손전등**(F): 약 110초 지속, 가로등 아래에서 충전, 건전지 +45%. 15% 미만이면 깜빡입니다.
- **그림자**: 정전 이후 거리를 배회하고, 빛 밖의 플레이어를 쫓습니다. 켜진 가로등 반경 안으로는 들어오지 못하며, 손전등을 1.7초 비추면 흩어졌다가 다시 나타납니다.
- 한 가로등(건널목)은 늘 불안정하게 깜빡입니다.

## 조작

WASD/방향키 이동, **R 벡독 타기/내리기(고속 라이딩)**, Shift 달리기, 클릭(포인터 잠금) 또는 드래그로 시점, V 1·3인칭 전환, E 행동/대화 진행, F 손전등, J 일지, M 서울·마을 지도, L 목록, P 일시정지. 터치 기기에서는 왼쪽 이동 패드와 행동·벡독 타기·손전등·달리기 버튼을 씁니다. 시점은 설정에서도 고를 수 있고 이 기기에 저장됩니다.

## 몽상녀와 벡독 · 서울 확장 월드

- 몽상녀는 승인된 턱선 단발·가벼운 앞머리·검정 골지 캐미솔·숏팬츠·맨발을 바탕으로 만든 성인 로우폴리 아바타입니다. 얼굴은 스타일화했으며 실제 인물의 얼굴을 재현하지 않습니다. 계층 행렬로 팔·다리·고개를 움직입니다.
- **벡독 탑승(라이딩)**: 언제든 `R` 키(또는 상단/터치 `벡독 타기` 버튼, 벡독을 바라보고 `E` 키)를 누르면 몽상녀가 벡독 등에 올라타며, 3인칭 추적 카메라로 자동 전환되어 약 2.15배 빠른 속도로 서울 전역과 몽상로를 질주할 수 있습니다.
- **서울시 실제 지형·랜드마크 반영 월드 확장**: 중앙 몽상로(`-36..44`)를 넘어 `-96..96 × -84..84` 규모로 맵을 확장하여 **종로 광화문광장·경복궁**, **강서 화곡·마곡 서울식물원 온실 돔**, **마포 홍대 어울마당로**, **용산 남산공원·N서울타워**, **성동 성수동 연무장길 붉은벽돌 스튜디오**, **한강 수로와 4대 대교(양화·마포·한강·성수대교)**, **영등포 여의도 한강공원·서울달**, **강남역·테헤란로 빌딩 숲**, **송파 잠실 스카이라인 타워**를 3D 저폴리곤 공간과 지도(M)에 구현했습니다.
- 3인칭 카메라는 도보 시 약 1.25유닛(벡독 탑승 시 약 1.65유닛) 뒤에서 추적하고 어깨 옆으로 비켜섭니다. 벽과 카메라 사이 충돌을 검사해 당기며 가까워지면 아바타를 투명하게 합니다. 저장 좌표·충돌·상호작용은 플레이어 위치를 계속 사용하고 손전등 원점도 플레이어에 붙습니다.
- 벡독은 승인된 `companion.glb`를 수정하지 않고 로드 후 부위별 강체 관절로 나눕니다. 혀·입·침은 머리와 함께 움직입니다. 붉은 ENICO VECK 목줄과 태그, 약한 눈빛, 걷기·앉기·꼬리 흔들기·고개 돌리기를 더했습니다.
- 벡독 자산은 타이틀에서 내려받지 않고 산책을 시작하면 한 번 로드합니다. 플레이어가 실제로 걸은 경로를 따라가며, 깨어남·저장 불러오기와 긴 경로에서는 안전한 경로 지점으로 다시 합류합니다.
- 1유닛 안에서 벡독을 바라보고 E로 쓰다듬으면 숨이 25 회복됩니다(40초 재사용 대기). 1장부터 가까운 미수집 조각을 향해 냄새를 맡고 짖습니다. 그림자가 가까우면 경계하지만 기존 그림자 AI에는 개입하지 않습니다.

## 렌더링 (PS1 질감)

`utils/world-asset-renderer.ts`의 단일 WebGL 1 셰이더가 처리합니다.

- 짧은 변 기준 240줄 내부 해상도 + CSS 최근접 확대(설정에서 360p/고화질 선택)
- 저해상도 격자로 버텍스 스냅, 부분 어파인 텍스처 매핑
- 15비트 색 + 4×4 Bayer 디더
- 짧은 안개 거리, 달빛 반구 조명, 가로등·조각·자판기 등 점광원 8개(고정 반복으로 언롤), 손전등 스포트라이트
- 가로등·창문·네온 같은 발광 재질은 정전 시 함께 꺼짐. GLB에 구워진 약한 발광은 기본색에 곱해 어둠을 유지
- 비네트, 위험 시 붉은 번짐, 주사선은 셰이더 안에서 처리(전체 화면 DOM 레이어를 쌓지 않음)
- 위험·숨 부족 시 세계가 일렁이는 꿈 왜곡
- 타이틀은 한글 픽셀을 실제 복셀 메시로 압출한 입체 글자입니다. WebGL을 쓸 수 없으면 접근 가능한 HTML 제목을 표시합니다.
- 배너·대화·쪽지·지도·일지·설정·일시정지는 밝은 좌상단/어두운 우하단 베벨, 계단식 그림자와 정적 디더 패턴을 씁니다. 지속 HUD에는 반복 애니메이션이나 무거운 필터를 쓰지 않으며, 동작 줄이기 설정도 반영합니다.

절차적 소품(`utils/world-props.ts`): 하늘 돔, 별, 달, 빛무리, 꿈 조각, 후드 인물·고양이·그림자, 공중전화, 자판기, 우체통, 벤치, 문, 나방, 비·먼지 파티클(카메라 주위로 감싸 도는 앵커), 손전등 빛줄기. 프레임 조립은 `utils/world-scene.ts`.

## 소리

`utils/world-audio.ts`가 Web Audio로 전부 합성합니다(드론, 바람, 비, 가로등 전기음, 발소리, 심장박동, 정전·전원 복구, 기차, 공중전화 벨, 문, 엔딩 화음). 외부 음원을 내려받거나 재배포하지 않으며, 첫 사용자 입력(시작 버튼) 이후에만 재생됩니다.

## 충돌 보강

원본 충돌 지도에 없던 북쪽 주택 6채, 동쪽 담장, 쓰레기통·화분과 새 소품의 충돌 상자를 `GAME_COLLIDERS`로 더했습니다. `colliders.json`과 GLB는 바꾸지 않았습니다.

## 저장

`localStorage`의 `mongsangin.world.save.v1`(진행)과 `mongsangin.world.settings.v1`(설정). 읽기는 `parseGameSave`가 범위·알려진 ID만 허용하고, 저장은 try/catch로 감싸 저장소를 쓸 수 없어도 게임은 계속됩니다. 벡독의 경로·동작은 저장하지 않고 불러온 플레이어 위치에서 새로 만듭니다. 이전 저장과 설정도 호환됩니다.

## 검증

```sh
node --test test/*.test.mjs
./node_modules/.bin/tsc --noEmit -p test/tsconfig.world.json
WORLD_TEST_URL=http://127.0.0.1:3214 PLAYWRIGHT_MODULE=… node test/world.browser.mjs
WORLD_TEST_URL=http://127.0.0.1:3214 PLAYWRIGHT_MODULE=… node test/village-world-portal.browser.mjs
# 소유자 설정이 없는 플레이스홀더 환경에서는 WORLD_TEST_WORKSHOP_UNCONFIGURED=1 추가
```

`test/world-game.test.mjs`는 손전등→정전→단서→공중전화→문→새벽 전체 진행, 모든 상호작용 지점의 도달 가능성, 그림자 추적·가로등 경계·손전등 퇴치, 깨어남, 배터리, 저장 변조 거부를 확인합니다. `test/world-characters.test.mjs`는 카메라 벽 충돌과 투명도, 아바타 동작, 원본 GLB 보존과 전체 삼각형 분할, 벡독 경로·회복·경계·저장 호환을 확인합니다. 브라우저 회귀는 PC 시점 전환과 설정 저장, 모바일 설정·터치, 벡독 지연 로드·추종, 창 크기, 자산 실패 및 WebGL 대체 목록을 확인합니다. 모바일 검증은 Chromium 뷰포트 테스트이며 실제 iPhone Safari 검증과는 다릅니다.
